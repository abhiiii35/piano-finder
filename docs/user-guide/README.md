# Book A Piano Tuner — User Guides

Quick reference for all features. Pick the guide that matches your task.

- **Scheduling** — Calendar management, availability, time off, reschedule, proposed times, route planning, mileage
- **Customers & CRM** — Customer records, contacts, locations, pianos, billing, global search
- **Importing Clients** — Bulk import from spreadsheets, Gazelle, phone contacts, Google Contacts
- **Service Records** — Logging visits, readings, photos, timeline, trends, client pages
- **Reminders** — Automatic tune reminders, appointment reminders, template customization
- **Messages** — Inbox, direct messages with customers or technicians, message threads, email notifications
- **Calendar Feed and Data Export** — Subscribe from Google or Apple Calendar, download data as CSV
- **Payments and Invoices** — Tips, invoice logos, tax summaries, payment tracking
- **Insights** — Revenue trends, client retention, profitability, business metrics
- **Setup Notes** — System configuration (for administrators)

All guides use plain language with numbered steps. Technician-specific sections are marked **(Technician)**; customer-specific sections are marked **(Customer)**.
